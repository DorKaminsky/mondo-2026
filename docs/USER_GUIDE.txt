🎯 HOW PREDICTIONS WORK
────────────────────────────────────────

Every match has 5 SEPARATE things to predict. Get each one right,
get points. No "all or nothing" — you can be partially right and
still score.

PER MATCH — 5 BETS:
  1. Match result    (Home win / Draw / Away win)
  2. Home team goals (exact number, e.g. 2)
  3. Away team goals (exact number, e.g. 1)
  4. First scoring team (Home / Away / None for 0-0)
  5. Goal difference (exact difference, e.g. 1)

POINTS PER CORRECT BET:
  - Group stage:       2 pts each (max 10/match, "perfect ⭐")
  - Knockout R32→Final: 3 pts each (max 15/match)

PERFECT MATCH = all 5 bets correct. A ⭐ goes on your leaderboard
row. Worth bragging about.

EXAMPLE:
  You predict:  Brazil 2-1 France, first scorer Brazil
  Actual:       Brazil 2-1 France, first goal by Brazil
  → All 5 correct → 10 pts (group) + ⭐

  You predict:  Brazil 3-2 France, first scorer Brazil
  Actual:       Brazil 2-1 France, first goal by Brazil
  → Result ✓, home goals ✗, away goals ✗, first ✓, diff ✓
  → 3 of 5 correct × 2 = 6 pts (no ⭐)
